# JEM Silver en Web6

Los Parquet de estadísticas pertenecen al repositorio GitHub del portal y se
publican directamente en GitHub Pages.

Archivos mínimos esperados:

- `causa.parquet`
- `document.parquet`
- `link.parquet`
- `party.parquet`
- `party_conflict.parquet`

Estos archivos **no se alojan ni se descargan desde Hugging Face**.

Antes de hacer `git add`, copie aquí los Parquet reales de su directorio local.
El workflow de Web6 falla si alguno de los cinco archivos mínimos no existe.
